\section*{Data availability}
Data for this article, including the ground truth models and their training data, the enumerated design spaces, and the complete results of all optimization campaigns (per-iteration convergence, evaluations, candidate allocation options, and LLM agent logs), are available on GitHub at \url{https://github.com/Tripp5118/resource-allocation}. The code for the resource allocation framework, the ground truth model workflow, and the analysis scripts that reproduce all figures and tables in this article can be found at the same location. The version of the code and data employed for this study is version v1.0.1, archived on Zenodo~\cite{robinson2026agentic} at \url{https://doi.org/10.5281/zenodo.23111493}. The Fe-Co-Ni training data were obtained from Padhy \etal~\cite{padhy2024experimentally, padhy2024data}, available at \url{https://doi.org/10.5281/zenodo.10686272}, and the Ti-V-Nb-Mo-Hf-Ta-W training data from Hastings \etal~\cite{hastings2025leveraging}.
